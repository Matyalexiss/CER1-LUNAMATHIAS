# CER1-LUNAMATHIAS
INSTRUCCIONES GENERALES
1. El desarrollo de este certamen es individual y práctico, correspondiente a una entrega con presentación.
2. El proyecto deberá ser publicado en un repositorio público de GitHub cuyo nombre siga el formato: CER1-
APELLIDONOMBRE.
3. La entrega se realizará exclusivamente mediante Aula, adjuntando el enlace al repositorio GitHub y el proyecto
comprimido.
1. El sitio deberá desarrollarse utilizando HTML, CSS y un framework CSS.
2. La calificación del certamen es asignada en el momento de la presentación. Si un estudiante no presenta sin
motivo justificado sólo obtendrá el 30% de su nota.
3. Durante la presentación, cada estudiante deberá demostrar que comprende el código entregado, explicar las
decisiones adoptadas y realizar modificaciones sobre su proyecto cuando sean solicitadas.
4. La entrega constituye la evidencia sobre la cual se realiza la defensa. La existencia de una característica en el
proyecto no acredita por sí sola el dominio de la competencia evaluada.
